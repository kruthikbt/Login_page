## ✨ About The Project

**Login Page** is a modern and responsive authentication interface designed as part of my **Minor Project 2**.

The project focuses on creating a clean user experience using fundamental web development technologies while maintaining a professional and visually appealing interface.

The goal of this project was to strengthen my understanding of **HTML structure, CSS styling, responsive layouts, UI design, and frontend development fundamentals.**

---

## 🎯 Project Highlights

- 🔐 Clean and modern login interface
- 📱 Responsive design for different screen sizes
- 🎨 Professional UI styling
- 🖥️ Desktop and mobile friendly
- ⚡ Lightweight and fast
- 🧩 Simple and organized code structure
- 🌐 Deployed using GitHub Pages
